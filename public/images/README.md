# Assets to add

This project ships with hotlinked Unsplash placeholder images so it runs
out of the box. Before going live, replace these with licensed assets:

- `og-cover.jpg` (1200x630) — Open Graph / Twitter card image
- `grain.png` — a subtle seamless film-grain texture (optional, used by the
  `bg-grain` utility if you choose to apply it)
- `/public/videos/hero-river.mp4` — cinematic hero background video
  (recommend 1920x1080, under 8MB, muted-safe, 15-20s loop)

All other imagery currently points to `images.unsplash.com` and is
configured in `next.config.mjs` under `images.remotePatterns`. Swap in your
own photography of your rafts, camps, and rentals for a truly distinctive
result — stock photography is a placeholder, not the final brand.
